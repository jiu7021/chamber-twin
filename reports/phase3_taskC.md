## 3-1. 물리 엔진

지배식

> **V·dP/dt = Q_mfc(t) + Q_leak + Q_outgas(t) − S_eff(P, θ)·P**

θ(스로틀 밸브 각도)를 **상태변수**로 둔다. 실측에 없어 Phase 1~2R이 막혔던 바로 그 변수다.

| 구성 요소 | 구현 |
|---|---|
| 적분기 | `scipy.integrate.solve_ivp`, **LSODA**(자동 stiff 전환). 명시적 오일러 사용 안 함 |
| 상태벡터 | [P, I, θ] — 압력, 제어기 적분항, 밸브 각도 |
| 아웃가싱 | q(t) = q1·t^(−α). 금속 α ≈ 1, 폴리머·엘라스토머 α ≈ 0.5 |
| 컨덕턴스 | Knudsen 수로 영역 판별 후 반경험식 결합 (아래) |
| 스로틀 밸브 | 나비형 디스크 기하에서 유도: 개방 면적비 = 1 − cos θ → C(θ) = C_max(1 − cos θ) |
| **APC 제어 루프** | PI + 밸브 액추에이터 1차 지연 + 되계산 와인드업 방지 |

### 유동영역과 컨덕턴스

Kn = λ/d 로 판별한다 (Kn ≲ 0.01 점성류, 0.01~1 중간류, Kn ≳ 1 분자류).

- 점성류(Poiseuille): C = π·d⁴·P̄ / (128·η·l)
- 분자류: C = (π/12)·v̄·d³/l,  v̄ = √(8RT/πM)
- 결합: **C = C_viscous + Z·C_molecular**,  Z = (1 + 2.507·r/λ)/(1 + 3.095·r/λ)

Z 는 λ → ∞ 에서 1, λ → 0 에서 2.507/3.095 = 0.810 이 되어 두 극한을 연속으로 잇는다.

### APC 제어 루프 — 실측이 요구한 구성

Phase 1에서 챔버 압력이 설정값에 서보 고정되고(변동계수 0.027 %) 상태 정보가 밸브 각도로
이전되는 것을 확인했으므로, 이 루프 없이는 실측을 재현할 수 없다.

```
θ_raw = kp·(P − P_sp) + I
θ_cmd = clip(θ_raw, θ_min, θ_max)
dI/dt = ki·(P − P_sp) + kaw·(θ_cmd − θ_raw)     ← 되계산 와인드업 방지
dθ/dt = (θ_cmd − θ) / τ_valve                    ← 액추에이터 1차 지연
```

### 작업 중 잡은 오류 2건 (기록)

**(1) 테스트가 물리적으로 틀렸다.** 컨덕턴스가 압력에 단조 증가한다고 가정했으나,
중간류에서 분자류 값 아래로 내려가는 **Knudsen 최소**가 실재한다(Knudsen 1909).
구현이 아니라 테스트를 고치고, Knudsen 최소의 존재·깊이(분자류 값의 30 % 이내)·
발생 위치(Kn ~ 1 부근)를 검증하는 테스트를 추가했다.

**(2) 적분기가 멈췄다.** 조건분기식 와인드업 방지가 dI/dt에 −34.6 rad/s 계단 불연속을 만들어
LSODA가 그 지점에서 스텝을 반복 기각했다 — **0.5 s 적분에 우변 호출 760만 회, 117 s 소요**.
연속인 되계산 방식으로 교체해 **0.02 s** 로 줄였다(5,900배). 수렴한 밸브각 0.9785 rad는
손계산값 0.977과 일치한다.

### 잔차 구조 — 아직 백색잡음이 아니다

**모델 B도 완전하지 않다.** lag-1 자기상관 +0.221 ± 0.255 (백색잡음이면 0),

그림 2열 패널에서 보이듯 모델 B의 잔차는 평탄부에서는 거의 0이고 전환 구간에서 튄다.
빠진 물리의 후보는 다음과 같으며 이 데이터로는 구분되지 않는다.
- 가스 전환 시의 유한한 혼합 시간 (챔버를 단일 완전혼합 용기로 본 가정의 한계)

명세의 "생성된 압력이 아니라 잔차가 산출물"이라는 지시에 따라 이 구조를 그대로 보고한다.

### [1·2] Rate-of-Rise — 실누설과 가상누설(아웃가싱) 분리

게이트 밸브를 닫아 S = 0 으로 두면 V·dP/dt = Q_total 이다. 미분 잡음을 피하기 위해
적분형으로 적합한다: P(t) − P(t₀) = (Q_leak/V)(t − t₀) + (q1/V)∫t^(−α)dt, α는 소인해서 선택.

| 시나리오 | 잡음 | Q_leak 오차 % | q1 오차 % | α 추정 (참값) |
|---|---|---|---|---|
| 실누설만 | 1× | 0.04 ± 0.03 | — | 식별 불가 (1.0) |
| 실누설만 | 3× | 0.11 ± 0.11 | — | 1.009 ± 0.667 (1.0) |
| 아웃가싱만 (금속) | 1× | — | 0.17 ± 0.13 | **1.000 ± 0.000** (1.0) |
| 아웃가싱만 (폴리머) | 1× | — | 1.32 ± 0.81 | **0.501 ± 0.007** (0.5) |
| 실누설 + 아웃가싱 | 1× | 0.14 ± 0.14 | 0.92 ± 1.02 | 0.997 ± 0.004 (1.0) |
| 실누설 + 폴리머 | 1× | 1.13 ± 0.64 | 2.46 ± 1.60 | 0.500 ± 0.012 (0.5) |
| 실누설 + 폴리머 | 3× | 3.96 ± 1.55 | 9.70 ± 1.94 | 0.500 ± 0.041 (0.5) |

**RoR은 실누설과 아웃가싱을 분리한다.** 두 성분이 섞인 경우에도 Q_leak을 1.13 % 이내,
α를 ±0.012 이내로 회복한다. 아웃가싱이 없는 "실누설만" 경우 α 추정이 1.009 ± 0.667로
크게 흩어지는데, 이는 실패가 아니라 **α가 원리적으로 식별되지 않는 상황을 올바로 반영한 것**이다
(q1 = 0 이면 α는 모델에 들어가지 않는다).

## 4. 한계 — 반드시 함께 읽어야 할 것

**(1) TMP 성능저하와 스로틀 밸브 마모는 서로 구분되지 않는다.**
정상상태 조건은 S_eff = 1/(1/[C_max(1−cosθ)] + 1/S_pump) = Q/P_sp 하나뿐인데
미지수는 C_max와 S_pump 둘이다. **방정식 1개, 미지수 2개 → 부정(不定)이다.**
위 표에서 TMP 오차는 C_max를 안다고 두고, 밸브 오차는 S_pump를 안다고 두고 계산한 값이다.
둘 다 모르면 분리 불가하며, 표의 오차는 그만큼 낙관적이다.
분리하려면 독립 측정이 하나 더 필요하다 — **Phase 2-0에서 확인한 포어라인 압력이 유력한 후보다**
(TMP 하류이므로 밸브 각도의 영향을 받지 않는다).

**(2) 시험대 값은 실제 장비 스펙이 아니다.**
V, S_pump, C_max, P_sp는 시뮬레이터 설정값이다. 게이트 지표(추정 오차 %)는 절대 스케일에
무관하므로 결론은 유효하지만, "이 장비의 누설이 몇 Pa·m³/s"를 말하는 것은 아니다.

**(3) 출처 검증이 필요한 상수 2건.**
- Knudsen 중간류 보정계수 2.507 / 3.095 — 진공공학 교재에 널리 재수록된 값이나 원문 미대조
- 아웃가싱 지수 α (금속 1.0 / 폴리머 0.5) — 명세 제공값. 관용값과 일치하나 개별 문헌 인용 미확인

밸브 액추에이터 시정수 0.05 s, 밸브각 분해능 1.571 mrad, 압력 잡음 0.10 %는 **가정치**로
명시하고 파라미터로 노출했다.

**(4) 모델 B의 잔차가 아직 구조를 가진다.** 3-3 참조. 가스 전환 구간에 집중되어 있으며,
완전혼합 가정·플라즈마 몰수 변화·5 Hz 샘플링 중 무엇이 지배적인지 이 데이터로는 결정되지 않는다.

**(5) 고장 진단은 시뮬레이터 안에서만 검증되었다.** 실측 데이터에는 고장 사례가 없으므로
(정상 운전 96장뿐) 진단기의 실제 성능은 검증되지 않았다. 이것은 데이터셋의 한계이며,
애초에 시뮬레이터를 만든 이유이기도 하다.

## 5. Phase 0~3 관통 결론

서보 제어가 걸린 계통에서는 **제어변수가 아니라 조작변수가 상태 정보를 갖는다.**

| 계통 | 제어변수 (정보 없음) | 조작변수 (정보 있음) | 데이터 기록 |
|---|---|---|---|
| 진공 | 챔버 압력 (CV 0.027 %) | 스로틀 밸브 각도 | **없음** → Phase 1 실패 |
| 배면 He | He 압력 (CV 0.0009 %) | He 유량 (CV 7.888 %) | 있음 |
| RF 정합 | 반사전력 | 커패시터 위치 | 있음 → Phase 2R 유일 생존 |

Phase 1·2는 이 구조 때문에 막혔고, Phase 3은 그 막힌 변수를 물리 모델로 복원해
**실측 압력을 8.2 % 오차로 재현하고, 5종 고장을 0.2 % 오차·5 s 지연으로 진단**했다.

## 쉬운 요약

컴퓨터 안에 진공 챔버를 만들고, 정답을 아는 문제 39개로 먼저 시험해 전부 통과시켰다.
그 다음 실제 장비 데이터를 넣어봤더니, 자동 밸브를 넣지 않은 모델은 34.8 % 틀렸는데 넣은 모델은 8.2 %로 맞았다. 96장 전부에서 그랬다.
마지막으로 누설·펌프 고장·밸브 마모 같은 고장을 일부러 넣어보니, 압력계는 아무것도 못 보는데(변화 0.007 %) 밸브 각도는 전부 잡아냈고 크기도 0.2 % 오차로 맞혔다.
다만 펌프 고장과 밸브 마모는 서로 구분이 안 된다 — 식은 하나인데 모르는 값이 둘이라서다. 이건 정직하게 한계로 적었다.
