## 2. 경로 2 — 정상상태 S_eff = Q_in / P_ss

각 웨이퍼에서 스텝 상승에지에 위상정렬한 앙상블 평균 사이클(긴 스텝 n≈98, 짧은 스텝 n≈99)을 만들고
평탄부(긴: 상대시각 2.0~4.2 s, 짧은: 0.9~1.35 s)의 중앙값을 썼다.
Q_in은 챔버 가스 채널 합(Gas1,2,3,4,5,7,8)이며, He 배면 유량은 별도 회로이므로 기본 제외했다(민감도 항목으로 별도 산출).

96 웨이퍼 통계:

| 항목 | 긴 스텝 | 짧은 스텝 |
|---|---|---|
| P_ss | 0.040027 ± 0.000011 | 0.050118 ± 0.000123 |
| Q_in | 606.576 ± 0.153 | 306.451 ± 0.149 |
| **S_eff (경로 2)** | **15154.36 ± 5.13** | **6114.62 ± 15.10** |
| P_ss 변동계수 | 0.0267 % | 0.2445 % |
| 평탄부 압력 드리프트 | +0.363 % | −1.358 % |

96장·2개월에 걸쳐 P_ss의 변동계수가 0.027%다. 이 값 자체가 5절 결론의 첫 근거다.

## 3. 경로 1 — 과도응답 τ

앙상블 평균 사이클에 P(t) = P_inf + (P_0 − P_inf)·exp(−t/τ)를 비선형 최소제곱 피팅했다.
전환 직후 밸브·MFC 응답 지연 구간은 제외하고, 제외 길이를 파라미터화해 민감도를 확인했다.

| 항목 | 긴 스텝 | 짧은 스텝 |
|---|---|---|
| τ (기본 창) | 0.3341 ± 0.0078 s | 0.2470 ± 0.0117 s |
| 피팅 R² | 0.9898 ± 0.0018 | 0.9907 ± 0.0023 |
| 제외구간 민감도 범위 | 0.174 ~ 0.334 s (**1.92배**) | 0.178 ~ 0.392 s (**2.21배**) |

**τ는 잘 결정되지 않는다.** 개별 창에서의 피팅 R²는 0.99로 높지만, 제외 구간을 0.3→0.4→0.5→0.7 s로
바꾸면 τ가 2배 가까이 흔들린다. R²가 높은 것은 3~9개 점에 3파라미터를 맞춘 결과일 뿐이다.

원인은 샘플링 한계다. dt = 0.2 s인데 τ ≈ 0.25~0.33 s이므로 τ/dt = 1.24 ~ 1.67이다.
1차계 식별에는 통상 τ/dt ≳ 5가 필요하므로 이 데이터는 이 측정에 대해 3~4배 부족하다.
앙상블 평균으로 압력 양자화(최소단위 1e-4) 잡음은 평균의 표준오차 기준 약 1e-5까지 줄였지만,
**시간 해상도는 평균으로 개선되지 않는다.** 사이클 간 에지 위상 분산이 샘플 간격의 0.046배(표준편차)에
불과해 등가시간 샘플링에 의한 초해상도 결합도 불가능했다.

## 4. 게이트 판정 — 실패

x = Q/P_ss, y = 1/τ, 원점통과 회귀. 모델상 1/τ = S_eff/V = (Q/P_ss)/V 이므로 기울기의 역수가 V다.

### 4-1. 통합 192점 (긴 + 짧은)

```
원점통과 기울기 = 2.628603e-04 ± 1.17e-05   → V = 3,804.3
비중심 R²(원점통과)  = 0.7245
절편 포함 OLS: 기울기 = -1.1743e-04  (음수)
              절편   = 4.7747 ± 0.0260,  95% CI = [4.7234, 4.8259]  → 0 미포함
              표준 R² = 0.9349                                      → 0.95 미달
```

산점도는 명확히 두 군집으로 갈라진다.

| 군집 | x = Q/P_ss | y = 1/τ [1/s] |
|---|---|---|
| 긴 스텝 | 15154.36 ± 5.13 | 2.9950 ± 0.0712 |
| 짧은 스텝 | 6114.62 ± 15.10 | 4.0569 ± 0.1849 |

x가 2.48배 큰 긴 스텝의 y가 오히려 **더 작다**. 모델은 y ∝ x를 요구하므로 부호부터 어긋난다.
통합 회귀의 기울기가 음수인 이유가 이것이다.

### 4-2. 군집 분리 회귀 (지시사항 3)

| | 긴 스텝 (n=96) | 짧은 스텝 (n=96) |
|---|---|---|
| 원점통과 기울기 | 1.976326e-04 ± 4.79e-07 | 6.635110e-04 ± 2.99e-06 |
| **V = 1/기울기** | **5,059.9** | **1,507.1** |
| 비중심 R² | 0.9994 | 0.9981 |
| 표준 R²(OLS, 절편 포함) | 0.0092 | 0.3665 |
| 절편 95% CI | [−60.05, 25.66] → 0 포함 | [−53.48, −29.07] → 0 미포함 |

기울기 비(짧은/긴) = **3.357**. 공통 V라면 1.000이어야 한다. V 불일치율 70.2%.

비중심 R²가 0.998~0.999로 보이는 것은 **통과 근거가 아니다.** 원점통과 회귀의 비중심 R²는
x, y가 원점에서 멀리 떨어진 좁은 군집일 때 자동으로 1에 가까워진다. 같은 데이터의 표준 R²는
긴 스텝 0.0092, 짧은 스텝 0.3665다. 즉 군집 내부에서는 x와 y 사이에 사실상 관계가 없다.
군집 내 x의 변동계수가 0.034%(긴)/0.247%(짧은)로 너무 작아 회귀의 지렛대가 없기 때문이다.

### 4-3. 경로1·경로2 일치 (V = τ · S_eff)

| | V |
|---|---|
| 긴 스텝 | 5,062.7 ± 118.4 |
| 짧은 스텝 | 1,510.4 ± 69.4 |
| 불일치 | **235.2%** (허용 10%) |

### 4-4. τ 분포 단봉성

긴 스텝 τ: 평균 0.3341 s, 왜도 −0.54, 첨도 +0.21, Shapiro p = 0.117 (정규성 기각 못 함)
짧은 스텝 τ: 평균 0.2470 s, 왜도 +1.03, 첨도 +0.72, Shapiro p = 1.04e-05 (정규성 기각)
두 군 t검정 p = 5.14e-126 → 명백한 이봉. 지시대로 분리해 재분석했으나 4-2에서 보듯 분리 후에도 실패다.

### 4-5. 추가 진단 — 적분형 ODE 회귀 (미분 없이 V, S 동시 추정)

지수 피팅은 입력이 완전한 계단이라고 가정한다. 실제로는 MFC 램프가 0.3~0.5 s로 τ와 같은 크기다.
이 편향을 배제하기 위해 측정된 Q(t)를 그대로 입력으로 쓰는 적분형 선형회귀를 추가했다:

  P(t) − P(t₀) = a·∫Q dt − Σⱼ bⱼ·∫P·1ⱼ dt,   a = 1/V,  bⱼ = Sⱼ/V

이 추정기는 합성 해석해에 대해 V, S를 상대오차 0.2% 이내로 회복함을 pytest로 검증했다
(`tests/test_fit.py`, 단일구간·이구간·공통체적 3케이스).

실측 결과 (96 웨이퍼 평균):

| 모델 | 결과 | r² |
|---|---|---|
| 스텝별 S (공통 V) | V = 17,403, S_긴 = 16,799, **S_짧은 = −722** | 0.5030 |
| 단일 S | **V = −18,992**, S = 11,907 | **−0.2951** |

**물리적으로 불가능한 음의 배기속도와 음의 체적이 나온다.** 단일 S 모델은 r²가 음수, 즉
데이터의 평균선보다도 못 맞춘다. 지수 피팅의 R² 0.99와 정반대의 결론인데, 이것이 실상이다.
지수 피팅은 좁은 창에서 국소 기울기를 맞췄을 뿐이고, 한 주기 전체를 물리식으로 설명하려 하면
1차 모델은 완전히 무너진다.

## 5. 원인 — 챔버 압력이 스로틀 밸브로 서보 제어되고 있다

네 갈래 독립 증거가 같은 결론을 가리킨다.

### 근거 1. 고정 밸브 가설의 직접 반증

고정 컨덕턴스라면 P_ss ∝ Q_in이어야 한다.

| 양 | 값 |
|---|---|
| Q 비 (긴/짧은) | 1.979 |
| P_ss 비 (긴/짧은) | **0.799** |
| 두 스텝 간 요구되는 S_eff 비 | **2.478** |

유량이 2배인 스텝에서 압력이 오히려 낮다. 이를 수동적으로 설명하려면 스텝이 바뀔 때마다
배기속도가 2.48배 변해야 한다. 가스 물성 차이(SF6 M=146 vs C4F8 M=200)로 설명 가능한
터보분자펌프 배기속도 차이는 통상 ±20% 범위이며 (통상범위, 벤더 스펙시트 미확인 — 확정 인용 아님),
2.5배는 여기에 들어가지 않는다. **밸브가 스텝마다 움직인다고 볼 수밖에 없다.**

### 근거 2. 압력이 정확한 설정값에 고정된다

96 웨이퍼 전체에서 긴 스텝 P_ss = 0.040027, 범위 0.040005 ~ 0.040048 (변동계수 0.0267%).
짧은 스텝 P_ss = 0.050118 (변동계수 0.2445%). 2개월·10개 로트에 걸친 값이다.
0.0400 / 0.0501 이라는 정수적인 값과 이 재현성은 레시피 압력 설정값의 서명이다.

### 근거 3. 유량이 완전히 일정한 구간에서 압력이 언더슈트 후 복귀한다

`Day_2024_07_05_Wafer_02` 앙상블 (긴 스텝 상승 기준 상대시각):

| 상대시각 [s] | 0.52 | 0.92 | 1.32 | 1.72 | **1.92** | 2.32 | 2.92 | 3.72 | 4.12 |
|---|---|---|---|---|---|---|---|---|---|
| 챔버 압력 | 0.04513 | 0.04116 | 0.04019 | 0.03983 | **0.03981** | 0.03998 | 0.04015 | 0.04000 | 0.04000 |
| Q_tot | 606.3 | 606.3 | 606.3 | 606.3 | 606.3 | 606.3 | 606.4 | 606.5 | 606.5 |

입력이 606.3으로 완전히 일정한데 압력은 0.03981까지 내려갔다가 0.04000으로 되돌아온다.
상수 계수 1차계는 단조 수렴만 가능하고 언더슈트 후 복귀를 만들 수 없다. 적분동작을 가진
폐루프 제어기의 응답이다.

### 근거 4. 같은 데이터셋 안의 명백한 서보 회로와 서명이 일치한다

He 배면 회로는 제어 구조가 명확하다(압력을 제어하기 위해 유량을 조작).

| 채널 | 역할 | 96장 변동계수 |
|---|---|---|
| HeliumBPPressure | 제어변수 | **0.0009 %** |
| HeliumBPFlow | 조작변수 | **7.8883 %** (8,700배) |
| Pressure (챔버) | 제어변수 | **0.0377 %** |
| ForeLinePressure (하류, 비제어) | — | **0.4946 %** (13배) |

챔버 압력이 하류의 비제어 압력보다 13배 더 안정하다. 챔버가 수동적이라면 있을 수 없는 대소관계다.

### 결론과 파급

스로틀 밸브 각도 채널은 Phase 0에서 확인했듯 데이터셋에 없다. 따라서
- `S_eff = Q/P_ss`는 (레시피 유량)/(레시피 압력 설정값)의 재기술이다. 챔버 상태 정보가 없다.
- τ는 챔버 시정수 V/S가 아니라 (챔버 + 밸브 + 제어기) 폐루프 시정수다.
- **압력·유량만으로 유효 배기속도를 역산한다는 Task A의 설계는 이 데이터셋에서 성립하지 않는다.**

한 가지 조건부 관찰은 기록해 둔다. 단위가 sccm / Torr라고 **가정할 경우**(6절 참조, 미확정),
긴 스텝의 V_raw = 5,059.9는 64.1 L, 짧은 스텝의 1,507.1은 19.1 L에 해당한다.
200 mm DRIE 챔버 체적은 통상 30~80 L이므로 긴 스텝 값은 물리적으로 그럴듯한 범위에 있다.
다만 두 스텝이 3.36배 어긋나 있으므로 이것을 체적 추정치로 채택하지 않는다. 우연의 일치일 수 있다.

물리적 제약으로 후보를 좁힌다.

   Torr로 읽으면 챔버 42.4 mTorr / He 15.0 Torr. He 배면 압력의 통상 운전범위는 5~20 Torr이고
   DRIE Bosch 공정압은 통상 10~100 mTorr이므로 **양쪽 다 통상범위 한가운데에 들어온다.**
2. **ForeLine을 챔버와 같은 단위로 읽으면 133.5 Torr**가 된다. 터보분자펌프의 허용 배압은
   통상 1 Torr 미만~수 Torr이므로 이 값은 성립할 수 없다. **ForeLine은 챔버와 다른 단위다.**
   mTorr로 읽으면 0.1335 Torr = 17.8 Pa로 TMP 배압으로 타당하다.
3. **독립 교차검증**: 유량이 sccm이라고 가정하면 긴 스텝 총유량 606.6 sccm = 1.025 Pa·m³/s.

   200 mm DRIE 툴의 건식펌프+부스터 용량으로 타당하다. 포어라인을 Torr(16,900 Pa)로 읽으면
   0.21 m³/h가 되어 불가능하다. 이 교차검증은 **유량이 sccm이라는 가정에 의존**한다.

**정합적인 조합**: Pressure = Torr 계열, HeliumBPPressure = Torr 계열, ForeLinePressure = mTorr 계열, 유량 = sccm.

**확정할 수 없는 부분**: Torr 계열과 mbar 계열은 내부 증거로 분리되지 않는다.
챔버를 0.0424 mbar(= 31.8 mTorr), He를 14.99 mbar(= 11.2 Torr)로 읽어도 위 세 제약을 모두 만족한다.

## 7. 검증한 것 / 검증하지 못한 것

pytest 12개 통과 (`tests/test_units.py` 6, `tests/test_fit.py` 6).
`test_fit.py`는 합성 해석해 P(t) = Q/S + (P₀ − Q/S)·exp(−tS/V)에 대해
지수 피팅이 τ를, 적분형 ODE 회귀가 V와 구간별 S를 상대오차 0.2% 이내로 회복함을 확인했다.
즉 **추정기는 정상이고, 실측에서 실패한 것은 모델 전제다.**

검증하지 못한 것: 압력·유량의 절대 단위, 가스 종, 스로틀 밸브의 실제 거동(채널 부재).

## 8. 다음 단계 — 사용자 판단이 필요하다

Task A는 설계된 형태로는 이 데이터셋에서 성립하지 않는다. Phase 2는 Task A의 S_eff를 입력으로
쓰도록 되어 있으므로 그대로 진행하면 정보가 0인 변수를 회귀하는 셈이 된다. 선택지는 셋이다.

**(가) 진단 축을 챔버 압력에서 포어라인 압력으로 옮긴다 (권장).**
ForeLinePressure는 APC 하류라 서보의 영향을 받지 않고, 순번 추세가 p = 3.35e-19로 이미 확인됐다.
포어라인 압력은 러핑펌프 배기속도에 대한 스루풋의 지표이므로 `S_rough = Q/P_fore`로
**러핑 계통의 유효 배기속도**를 역산할 수 있다. 이 경우 Task A의 물리식은 그대로 살아나고
대상만 "챔버+TMP"에서 "TMP 하류 배기 계통"으로 바뀐다. 챔버 폴리머 퇴적이 아니라
배기 라인 퇴적·펌프 성능을 보게 된다는 점은 정직하게 기술해야 한다.
He 배면 유량(p = 0.0072)을 척 상태의 보조 지표로 함께 쓴다.

**(나) Task A를 "APC 제어 챔버에서는 압력만으로 배기속도를 역산할 수 없다"는 음성 결과로 확정하고,
Phase 3(시뮬레이터)으로 건너뛴다.** 실측 대조는 포어라인 기반으로 축소하고, 시뮬레이터는
밸브 각도를 포함한 순방향 모델 + 고장 주입에 집중한다. 면접 서사로는 "데이터가 무엇을
말할 수 없는지 먼저 규명했다"가 되며, 이것은 약점이 아니라 강점으로 설명할 수 있다.

**(다) 8 GB의 Day_*.nc를 받아 밸브 각도 채널을 찾는다.** Phase 0에서 확인한 대로 OES 파일이며
공정 파라미터가 아니라 스펙트럼일 가능성이 높다(Readme 2.1절). 성공 확률이 낮고 용량 대비 비효율이라
권장하지 않는다.

**(가)와 (나)를 결합하는 것이 가장 자연스럽다.** 어느 쪽으로 갈지 지시해 주면 진행한다.

## 쉬운 요약

압력을 보고 "배기가 얼마나 잘 되는지"를 계산하려 했는데 실패했다.
장비에 압력을 자동으로 일정하게 맞춰주는 장치가 달려 있어서, 압력이 2개월 내내 거의 똑같은 값(변동 0.027%)이었기 때문이다.
에어컨이 방을 24도로 맞추고 있으면 온도계만 봐서는 방이 더운지 알 수 없는 것과 같다. 알려면 에어컨이 얼마나 세게 도는지를 봐야 하는데, 그 값(밸브 각도)은 기록되지 않았다.
그래서 이 방법은 여기서 접고, 압력 말고 다른 신호를 찾기로 했다.
