## 2-a. 역산식 유도 — ABCD 행렬

무손실 2포트 정합망 M = [[A,B],[C,D]] 에서 Z_in = (A·Z_L + B)/(C·Z_L + D).
정합 상태 Z_in = Z0 를 대입하면 부하 임피던스가 **유일하게** 결정된다:

> **Z_L = (Z0·D − B) / (A − Z0·C)**  … (★)

구성요소: 직렬 임피던스 Z → [[1, Z],[0, 1]], 병렬 어드미턴스 Y → [[1, 0],[Y, 1]].
이하 모든 임피던스는 Z0 정규화 무차원(Z0 = 1).

### L형 (병렬 C_sh → 직렬 [고정 L + 가변 C_se])

M = [[1,0],[jb,1]]·[[1,jx],[0,1]] → (★) 대입 시 **닫힌 해석해**가 나온다:

> **R/Z0 = 1/(1 + b²)** ← **병렬 커패시터만으로 결정**
> **X/Z0 = b/(1 + b²) − x_se** ← 두 소자 모두 관여
> b = ω·C_sh·Z0,  x_se = (ω·L − 1/(ω·C_se))/Z0

### Π형 (병렬 C1 → 직렬 고정 L → 병렬 C2)
M = [[1,0],[jb1,1]]·[[1,jx],[0,1]]·[[1,0],[jb2,1]] → (★)로 Z_L 결정.

### T형 (직렬 C1 → 병렬 고정 L → 직렬 C2)
M = [[1,jx1],[0,1]]·[[1,0],[jb,1]]·[[1,jx2],[0,1]] → (★)로 Z_L 결정.

세 토폴로지 모두 **소자값을 알면 두 커패시터 위치로부터 (R, X)가 유일하게 결정된다**
(복소 방정식 1개 = 실수 방정식 2개, 미지수 2개). 역산 자체는 잘 정의된다.

## 2-b. 무엇이 결정되고 무엇이 미결정인가

**데이터에 없는 것 (가정하지 않고 미지수로 유지):**

| 미지수 | 상태 |
|---|---|
| ω (RF 주파수) | 채널 없음 |
| Z0 (발전기 임피던스) | 관례 50 Ω, 데이터에 명시 없음 |
| 고정 소자값 (L 또는 고정 C) | 채널 없음 |
| 커패시터 "위치(%) → 정전용량(F)" 변환 | 채널 없음, 통상 비선형 |
| 정합망 토폴로지 | 채널 없음 |
| 두 채널 중 어느 것이 병렬/직렬인지 | 채널 없음 (Load/Tune 명명 관례는 벤더마다 다름) |

**결론**

| 산출물 | 가능 여부 |
|---|---|
| 절대 임피던스 R [Ω], X [Ω] | **불가능.** 위 6개가 모두 필요하다 |
| 상대 변화 δlnR, δX (웨이퍼 1번 기준) | **가능.** 단 토폴로지·동작점을 소인(sweep)해야 함 |

진공 축에서 챔버 체적 V가 미지수라 상대 컨덕턴스만 구했던 것과 같은 처리다.

- **T형**: ∂lnR/∂lnC2 = 0 이지만 ∂lnR/∂lnC1 의 **부호가 x1 에 따라 바뀐다**

이하 상대지표는 L형을 가정해 산출하고, 두 채널의 병렬/직렬 배정은 양쪽 다 계산한다.

## 2-e. 상대 지표 (웨이퍼 1번 대비)

> δlnR = −2b²/(1+b²) · δln C_sh   (b = √(1/r0 − 1), 동작점 r0 소인)
> δX = b(1−b²)/(1+b²)² · δln C_sh − s · δln C_se   (s = 1/(ω·C_se·Z0) 소인)

소인 범위: r0 = R/Z0 ∈ {0.02, 0.05, 0.10, 0.20, 0.35, 0.50}
(통상범위: 용량결합 바이어스 부하 R ≈ 1~25 Ω @ Z0 = 50 Ω), s ∈ {0.1, 0.3, 1, 3, 10}.

**δlnR 은 병렬 커패시터 하나의 상수배, δX 는 두 채널의 1-매개변수 선형족**이다.

# 4단계 — 가설 소거

관측 데이터이며 로트–날짜가 교락되어 있으므로 인과 추론은 불가능하다. 아래는 **가설 소거**다.

## 4-a. 기전 가설과 물리에서 도출한 서명

Platen(바이어스) 전극이 보는 부하를 단순 집중정수로 두면
Z_L ≈ R_bulk + R_stoch + 1/(jω·C_sheath) + Z_return (접지 귀환 경로).

| # | 가설 | 물리 | 데이터에 남겨야 할 서명 |
|---|---|---|---|
| H1 | **내벽 유전체 폴리머 퇴적** | 플루오로카본 막(εr ≈ 2~3, 저손실)이 접지 귀환면에 직렬 커패시턴스 C_film = ε0εr A/t 를 삽입. 막이 두꺼워질수록 C_film ↓ → −1/(ωC_film) 이 더 음수 | **X 감소(더 용량성), R 거의 불변** |
| H2 | **챔버 벽 도전성 변화** (손실성/도전성 막) | 손실성 막은 귀환 경로에 직렬 저항을 추가 | **R 증가**, X 변화 작음 |
| H3 | **시스 특성 변화** | 플라즈마 밀도·이온속 변화로 시스 두께 d 변화. C_sheath ∝ A/d 이므로 d ↑ → X 더 음수. 동시에 확률가열 저항 R_stoch 도 변함 | **R 과 X 가 함께 변함 (연동)** |
| H4 | **웨이퍼 형상 변화** (깊은 트렌치) | 식각 깊이 44 µm 로 측벽 면적 증가. 다만 13.56 MHz 대역에서 시스 두께 ≫ 피처 폭이라 시스가 트렌치 내부를 따라가지 않음 | **서명 거의 없음** |
| H5 | **척 표면 폴리머 → 배면 He 실링 변화** | He 유량 −2.80 %/10장 (p = 0.00935) 로 이미 관측됨. 웨이퍼 온도에 작용하나 RF 임피던스에는 직접 경로가 약함 | **RF 지표에는 약한 서명** |

**소거된 것: H2 (챔버 벽 도전성 변화).** 배정·동작점 소인과 무관하게 R 증가 서명이 나타나지 않는다.
이것이 4단계에서 유일하게 확정적으로 얻은 결과다.

**구분 불가능한 것: H1 과 H3.** 두 가설은 정확히 배정 A/B 로 갈리는데,
**어느 채널이 병렬인지 데이터에 없으므로 구분할 수 없다.**
Load/Tune 명명 관례상 Load 가 병렬(배정 B, → H1 지지)인 경우가 흔하지만, 이는 벤더 관례이지
이 데이터셋의 증거가 아니다. 관례를 근거로 H1 을 채택하지 않는다.

**검정 불가능한 것: H4, H5.** 두 가설 모두 "RF 지표에 서명을 남기지 않는다"를 예측하므로
어떤 관측 결과와도 모순되지 않는다. 반증 가능성이 없어 이 데이터로는 다룰 수 없다.

**소인에 강건한 유일한 물리 결과**: 부하 리액턴스 X 는 로트가 진행될수록
**더 용량성 방향으로 이동한다** (배정·r0·s 전 조합에서 부호 음수 고정, 10장 누적 −0.002 ~ −0.11 Z0).
이것은 H1·H3 양쪽과 모두 정합적이므로 둘을 가르지는 못하지만, H2 기각의 근거를 보강한다.

## 4-c. 배정 모호성을 깨려면 필요한 것

- 정합망 회로도 또는 소자 배치 (어느 커패시터가 병렬인지)
- 전극단 V-I 프로브 (Z_L 직접 측정 — 역산 자체가 불필요해짐)
- 주파수 스윕 (저항 성분과 용량 성분의 주파수 의존성이 다름)
- 커패시터 위치–정전용량 교정 곡선

넷 다 이 데이터셋에 없다.

# Phase 2R 종합

1. **1단계**: −145 % 부호 반전은 **공선성**(억제변수 아님). 순번 축 위의 RF 실질 자유도는 **1**.
2. **2단계**: 역산은 잘 정의되나 절대값은 불가. 변위가 0.4 % 라 역산은 **원시 채널의 선형 재매개화**이며
   **통계적 정보를 추가하지 않는다** (부분상관이 소수 셋째 자리까지 동일).
3. **3단계**: 임피던스 지표 7/16 조합이 Bonferroni 생존, **정합 품질 지표는 8/8 전부 소멸**.
4. **4단계**: **H2(벽 도전성 변화) 기각.** H1(유전체 폴리머)과 H3(시스 변화)은 병렬/직렬 배정 모호성으로
   **구분 불가**. H4·H5 는 반증 가능성이 없어 검정 불가.

**Phase 3 으로 인계**: 임피던스 역산은 해석을 정교하게 했을 뿐 예측력을 늘리지 못했다.
이것은 Phase 3(물리 기반 시뮬레이터)의 필요성을 다시 확인해 준다 —
미측정 상태변수(스로틀 밸브 각도 θ, 정합망 토폴로지·소자값)를 복원하지 않으면
관측 채널만으로는 여기까지가 한계다.

## 쉬운 요약

플라즈마에 전기를 넣어주는 장치에는 손잡이 두 개가 있는데, 이게 챔버 상태에 따라 자동으로 돌아간다. 언덕 경사를 직접 못 재도 자전거 기어 단수를 보면 짐작할 수 있는 것과 같다.
이 손잡이 위치를 전기 물리량으로 번역하는 계산식을 회로 구조 3가지 경우에 대해 각각 세웠다.
그런데 손잡이가 워낙 조금(0.4%)만 움직여서, 번역해도 숫자에 상수만 곱해질 뿐 정보량은 그대로였다. 예측이 좋아지지 않았다.
대신 "챔버 벽이 전기가 통하게 변한 것은 아니다"라는 가설 하나는 확실히 지웠다. 나머지 두 가설은 손잡이 배선 정보가 없어서 구분하지 못했다.
