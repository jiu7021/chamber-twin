# Modbus TCP 레지스터 맵 — 챔버 디지털 트윈 ↔ OpenPLC ↔ SCADA

## 0. 구성

```
 ┌──────────────────────────┐   Modbus TCP    ┌──────────────────┐   Modbus TCP   ┌──────────┐
 │ chamber_twin (Python)    │◄───────────────►│ OpenPLC Runtime  │◄──────────────►│  SCADA   │
 │  = 플랜트 (챔버 물리모델)  │  포트 5020      │  = 제어기         │   포트 502     │  = HMI   │
 │  Modbus **슬레이브**      │  OpenPLC가       │  APC PI · 알람    │  SCADA가        │          │
 │  physics/chamber.py 구동  │  마스터로 폴링    │  인터록 · RoR     │  마스터로 폴링   │          │
 └──────────────────────────┘                 └──────────────────┘                └──────────┘
```

**Hardware-in-the-Loop 구성이다.** 제어(APC PI)는 실제 PLC가 수행하고, 플랜트(챔버)만 시뮬레이션한다.
따라서 PLC 로직·알람·인터록을 실제로 검증할 수 있다.

- **레이어 1** (포트 5020): 트윈이 슬레이브. OpenPLC가 마스터로 계측값을 읽고 밸브 지령을 쓴다.
- **레이어 2** (포트 502): OpenPLC 내장 슬레이브. SCADA/HMI가 마스터로 읽는다.

## 1. 스케일 규약

Modbus 레지스터는 16비트다. 공학단위를 정수로 옮기기 위해 아래 배율을 쓴다.

| 규약 | 내용 |
|---|---|
| 정수형 | 별도 표기 없으면 **부호 없는 16비트** (0~65535) |
| 부호 있는 값 | `INT16` 표기. 2의 보수 (−32768~32767) |
| 배율 | 공학값 = 레지스터값 ÷ 배율. 예) 압력 4012 ÷ 100 = 40.12 mTorr |
| 바이트 순서 | 빅엔디안 (Modbus 표준) |
| 32비트 값 | 하위워드 먼저(LSW first), 2워드 연속. 표에 `U32` 표기 |
| 무효값 | 65535 (U16) / 32767 (INT16) 은 "측정 불가" 를 뜻한다 |

**단위 규약**: 내부 물리 계산은 SI 단일계(Pa, m³/s, Pa·m³/s)로 하고,
Modbus 경계에서만 표시 단위(mTorr, L/s)로 환산한다. 환산은 `physics/units.py` 를 쓴다.

## 2. Input Register (FC 04, 읽기 전용) — 계측값 : 트윈 → PLC/SCADA

| 주소 | 태그 | 설명 | 단위 | 배율 | 범위 |
|---|---|---|---|---|---|
| IR 0 | `PT_CHAMBER` | 챔버 압력 | mTorr | ×100 | 0~65535 (0~655 mTorr) |
| IR 1 | `PT_FORELINE` | 포어라인 압력 | mTorr | ×10 | 0~6553 mTorr |
| IR 2 | `ZT_VALVE` | **스로틀 밸브 각도** | deg | ×100 | 0~9000 (0~90°) |
| IR 3 | `ZT_VALVE_OPEN` | 밸브 개방률 | % | ×100 | 0~10000 |
| IR 4 | `FT_SEFF` | 유효 배기속도 S_eff | L/s | ×10 | 0~65535 |
| IR 5 | `FT_QTOTAL` | 총 스루풋 Q_total | Pa·m³/s | ×10000 | 0~6.5 |
| IR 6 | `FT_MFC_PV` | MFC 실측 유량 | Pa·m³/s | ×10000 | 0~6.5 |
| IR 7 | `KN_NUMBER` | Knudsen 수 | — | ×10000 | 0~6.5 |
| IR 8 | `FLOW_REGIME` | 유동영역 | 코드 | — | 0=점성류 1=중간류 2=분자류 |
| IR 9~10 | `ET_RUNTIME` | 경과 시간 (U32) | s | ×10 | LSW 먼저 |
| IR 11 | `EST_QLEAK` | RoR 추정 실누설 | Pa·m³/s | ×1e6 | 0~0.065 |
| IR 12 | `EST_Q1` | RoR 추정 아웃가싱 q₁ | Pa·m³/s | ×1e6 | 0~0.065 |
| IR 13 | `EST_ALPHA` | RoR 추정 지수 α | — | ×1000 | 0~65 |
| IR 14 | `EST_PUMP_HEALTH` | TMP 성능 추정 | % | ×100 | 0~10000 |
| IR 15 | `EST_VALVE_HEALTH` | 밸브 C_max 추정 | % | ×100 | 0~10000 |

> **IR 14 · 15 는 서로 독립이 아니다.** 정상상태 방정식이 하나뿐이라
> (S_eff = 1/[1/C_max(1−cosθ) + 1/S_pump] = Q/P_sp) 두 값을 동시에 결정할 수 없다.
> 트윈은 한쪽을 정상으로 가정하고 다른 쪽을 역산한다. 어느 쪽을 가정했는지는 `DI 12` 로 알린다.
> 분리하려면 독립 측정이 하나 더 필요하다 — 포어라인 압력(IR 1)이 후보다.

## 6. 알람 설계 근거

| 알람 | 임계 근거 |
|---|---|
| `ALM_P_HIGH` / `ALM_P_LOW` | 설정값 ±10 %. **실측에서 압력 변동계수가 0.027 % 였으므로 이 알람은 사실상 울리지 않는다.** 압력만으로는 고장을 못 잡는다는 본 프로젝트의 결론을 그대로 반영한 값이다. |
| `ALM_VALVE_DRIFT` | **핵심 알람.** 밸브각이 기준 대비 유의하게 열리면 배기계 열화를 의심한다. 시뮬레이션에서 TMP 70 % 저하 시 각도가 0.4673 → 0.4826 rad (+3.3 %) 이동했다. |
| `ALM_REAL_LEAK` / `ALM_OUTGAS` | RoR 적합 결과. q₁ > 0.5·\|Q_leak\| 이면 아웃가싱 우세로 본다. 실측 수준 잡음에서 α 추정 표준편차 ±0.012 로 두 기전이 분리된다. |
| `ILK_GAS_BLOCK` | 게이트 폐쇄 상태에서 가스를 넣으면 압력이 무한정 상승한다. 하드 인터록. |
| `ILK_VALVE_SAT` | 밸브가 완전개방에서 지속 포화하면 더 이상 압력을 낮출 수 없다 — PM 요구 신호. |

## 7. 폴링 주기 권장값

| 구간 | 주기 | 근거 |
|---|---|---|
| OpenPLC → 트윈 | **200 ms** | 실측 데이터셋의 5 Hz 와 동일하게 맞췄다 |
| SCADA → OpenPLC | 500 ms~1 s | HMI 갱신에 충분 |
| PLC 스캔 | 100 ms | APC 루프 대역폭(밸브 시정수 50 ms)의 2배 여유 |

**주의**: 5 Hz 샘플링은 챔버 과도응답(τ ≈ 0.25~0.33 s)을 식별하기에 τ/dt = 1.24~1.67 로 부족하다.
정상상태 진단(밸브각 역산, RoR)은 이 주기로 충분하지만, 과도응답 기반 진단을 추가하려면
최소 20 Hz 이상이 필요하다.
