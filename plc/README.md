# OpenPLC · SCADA 연동

챔버 디지털 트윈을 **Modbus TCP 슬레이브**로 노출해 실제 PLC 로 제어하고 SCADA 로 감시한다.

```
 ┌───────────────────────────┐  Modbus TCP  ┌─────────────────┐  Modbus TCP  ┌────────┐
 │ modbus_server.py          │◄────:5020───►│ OpenPLC Runtime │◄────:502────►│ SCADA  │
 │  플랜트 — 챔버 물리모델      │   OpenPLC가   │  제어기          │   SCADA가     │  HMI   │
 │  physics/chamber.py       │   마스터      │  openplc_apc.st  │   마스터      │        │
 └───────────────────────────┘              └─────────────────┘              └────────┘
```

**Hardware-in-the-Loop 구성이다.** 제어 로직(APC PI · 알람 · 인터록 · RoR 시퀀스)은 실제 PLC 가
수행하고 챔버만 시뮬레이션한다. 따라서 PLC 프로그램을 장비 없이 실제로 검증할 수 있다.

| 파일 | 역할 |
|---|---|
| `modbus_map.md` | **레지스터 맵 규약.** 다른 파일은 전부 이 문서의 구현이다 |
| `modbus_tcp.py` | 최소 Modbus TCP 슬레이브·마스터 (외부 의존성 없음) |
| `modbus_server.py` | 챔버 플랜트 + RoR 시퀀서 + 진단 추정기를 Modbus 로 노출 |
| `openplc_apc.st` | OpenPLC 용 IEC 61131-3 Structured Text 제어 프로그램 |

## 1. 트윈 단독 실행 (PLC 없이)

```bash
python plc/modbus_server.py --port 5020 --local-apc
```

`--local-apc` 는 PLC 없이 내부 APC 로 압력을 잡는다. 배선 확인용이다.

물리만 빠르게 확인하려면:

```bash
python plc/modbus_server.py --headless-demo 400 --local-apc
```

출력 예 (200 s 에 누설 0.10 Pa·m³/s 주입):

```
  주입 직전 : P =  40.0000 mTorr, θ = 26.7668°
  최종      : P =  40.0000 mTorr, θ = 28.3066°
  압력 변화 : +0.00000 %
  밸브 변화 : +5.7524 %
```

**압력은 전혀 움직이지 않고 밸브 각도만 움직인다.** 실측 96 웨이퍼에서 관찰한 현상의 재현이다.

## 2. 동작 검증 (내장 마스터)

```bash
python - <<'PY'
import sys; sys.path.insert(0, '.')
from plc.modbus_tcp import ModbusTcpClient
c = ModbusTcpClient("127.0.0.1", 5020)
r = c.read_input_registers(0, 16)
print(f"압력 {r[0]/100:.3f} mTorr | 밸브 {r[2]/100:.3f}° | S_eff {r[4]/10:.1f} L/s")
c.write_register(16, 30000)          # INJ_QLEAK = 0.03 Pa·m³/s
PY
```

RoR 진단 검증 결과 (게이지 양자화 0.25 % 포함, 60 s 측정):

| 시나리오 | Q_leak 오차 | q₁ 오차 | α (참값) | 판정 |
|---|---|---|---|---|
| 실누설만 | **+0.0 %** | — (올바로 기각) | — (1.00) | 실누설 |
| 아웃가싱만 (금속) | — | **−0.2 %** | **1.000** (1.00) | 아웃가싱 |
| 아웃가싱만 (폴리머) | — | **−0.1 %** | **0.500** (0.50) | 아웃가싱 |
| 실누설 + 아웃가싱 | **+0.0 %** | **−0.2 %** | **1.000** (1.00) | 아웃가싱 |

## 3. OpenPLC 설정

### 3-1. 프로그램 등록
1. OpenPLC Web (`http://<plc>:8080`) → **Programs** → `plc/openplc_apc.st` 업로드 → Compile
2. **Settings** → Modbus 슬레이브(SCADA 용) 활성화, 포트 502

### 3-2. 트윈을 원격 장치로 등록
**Slave Devices** → *Add new device*

| 항목 | 값 |
|---|---|
| Device Name | `chamber_twin` |
| Device Protocol | **ESP32 / Generic Modbus TCP Device** |
| IP Address | 트윈이 도는 호스트 |
| IP Port | `5020` |
| Discrete Inputs (%IX100.0) | Start 0, Size 16 |
| Input Registers (%IW100) | Start 0, Size 16 |
| Coils (%QX100.0) | Start 0, Size 8 |
| Holding Registers (%QW100) | Start 0, Size 22 |

이 설정이 `openplc_apc.st` 의 `AT %IW100 …`, `AT %QW100 …` 선언과 대응한다.
주소를 바꾸면 ST 의 located variable 도 함께 바꿔야 한다.

### 3-3. 폴링 주기 — 200 ms 를 넘기면 안 된다

**Settings** → Modbus polling period **200 ms** (실측 데이터셋의 5 Hz 와 동일).
PLC 스캔 주기는 ST 하단 `TASK MainTask(INTERVAL := T#100ms)` 로 100 ms 다.

이 값은 임의가 아니다. 루프 지연이 챔버 시정수와 맞먹기 때문에 폴링을 늦추면 제어가 무너진다.

| 폴링 주기 | 위상여유 | 스텝 오버슈트 | 판정 |
|---|---|---|---|
| 50 ms | +93.0° | +2.90 % | 안정 |
| 100 ms | +89.8° | +3.38 % | 안정 |
| **200 ms** | **+83.3°** | **+7.14 %** | **안정 (권장)** |
| 500 ms | +63.9° | +22.19 % | **불안정** |
| 1000 ms | +31.6° | +66.91 % | **불안정** |
| 2000 ms | — | +1411 % | **발산** |

`python plc/hil_check.py` 로 재현할 수 있다.

### 3-4. PI 이득 검증

루프 지연은 폴링 200 ms + 스캔 100 ms/2 + 밸브 지연 50 ms = **300 ms** 이고,
챔버 시정수는 V/S_eff = **0.267 s** 다. **지연/시정수 = 1.13** — 지연이 시정수와 맞먹는다.
이 조건에서는 이득을 크게 잡으면 진동한다.

| 이득 | 위상여유 | 스텝 오버슈트 | 설정값 교차 | 외란 정착 | 판정 |
|---|---|---|---|---|---|
| KP 0.40 / KI 1.60 (초기안) | +20.0° | +22.94 % | 138 회 | 7.8 s | **부적합** |
| **KP 0.20 / KI 0.40 (채택)** | **+83.3°** | **+7.14 %** | **1 회** | **4.1 s** | 채택 |
| KP 0.05 / KI 0.05 (보수적) | +93.2° | +0.83 % | 1 회 | 32.5 s | 외란 제거가 느리다 |

채택 기준은 **위상여유 ≥ 60°, 오버슈트 ≤ 8 % 중 교차주파수 최대**다.
교차주파수가 높을수록 고장(외란) 제거가 빨라 밸브각이 새 평형에 빨리 도달하고,
그래야 밸브각 역산 진단이 유효해진다.

> **외란 정착 4.1 s 이후에야 밸브각 역산이 유효하다.** 고장 직후에는 밸브가 아직 움직이는
> 중이므로 IR 14/15 의 성능 추정값을 읽으면 안 된다.

## 4. SCADA 연결

SCADA(ScadaBR · Ignition · FUXA · 그 외 Modbus 마스터)를 OpenPLC 내장 슬레이브(포트 502)에 붙인다.

| SCADA 태그 | 주소 | 방향 | 설명 |
|---|---|---|---|
| `HMI_AUTO` | Coil 0 | 쓰기 | 자동/수동 |
| `HMI_RUN` | Coil 1 | 쓰기 | 공정 운전 |
| `HMI_ROR_REQ` | Coil 2 | 쓰기 | RoR 시퀀스 요청 |
| `HMI_ALM_RESET` | Coil 3 | 쓰기 | 알람 리셋 |
| `HMI_SP` | HR 0 | 쓰기 | 압력 설정값 mTorr ×100 |
| `HMI_MFC` | HR 1 | 쓰기 | MFC 지령 ×10000 |
| `HMI_MAN_VALVE` | HR 2 | 쓰기 | 수동 밸브각 deg ×100 |
| `ALM_P_HIGH` | Coil 8 | 읽기 | 압력 상한 |
| `ALM_P_LOW` | Coil 9 | 읽기 | 압력 하한 |
| **`ALM_VALVE_DRIFT`** | Coil 10 | 읽기 | **밸브각 드리프트 — 주 진단 알람** |
| `ALM_REAL_LEAK` | Coil 11 | 읽기 | 실누설 |
| `ALM_OUTGAS` | Coil 12 | 읽기 | 아웃가싱 |
| `ILK_GAS_BLOCK` | Coil 13 | 읽기 | 인터록: 가스 차단 |
| `ILK_VALVE_SAT` | Coil 14 | 읽기 | 인터록: 밸브 포화 |

> OpenPLC 의 `%QX0.0` 은 Coil 0, `%QX1.0` 은 Coil 8 에 대응한다(바이트 단위 매핑).

### HMI 화면 설계 권고

압력 트렌드를 큰 화면에 두는 통상적 배치는 **이 설비에서 쓸모가 없다.** 압력은 설정값에 고정된다.

- 주 트렌드: **밸브 각도**, 기준선과 드리프트 임계선을 함께 표시
- 보조 트렌드: 포어라인 압력 (APC 하류라 배기계 상태를 반영)
- 압력 트렌드: 작게. 정상 확인용이지 진단용이 아니다
- RoR 결과 패널: Q_leak · q₁ · α 와 판정 문구

## 5. 알람 설계 근거

| 알람 | 임계 | 근거 |
|---|---|---|
| `ALM_P_HIGH/LOW` | 설정값 ±10 % | **실측 압력 변동계수가 0.027 % 였으므로 사실상 울리지 않는다.** 압력만으로는 고장을 못 잡는다는 결론을 그대로 반영한 값이다 |
| **`ALM_VALVE_DRIFT`** | 기준 대비 **+1.5 %**, 20 스캔(2 s) 지속 | **주 진단 알람.** 밸브각 계측 분해능이 기준각의 0.34 % 이므로 약 4.4σ 다. 검출 범위는 아래 표 참조 |
| `ALM_REAL_LEAK` | Q_leak > 5e-3 Pa·m³/s 이고 q₁ ≤ 0.5·Q_leak | RoR 적합 결과 |
| `ALM_OUTGAS` | q₁ > 0 이고 q₁ > 0.5·Q_leak | 아웃가싱 항이 모델선택(ΔAIC ≥ 10 · α 비경계 · 기여도 ≥ 5 %)을 통과한 경우에만 |
| `ILK_GAS_BLOCK` | 게이트 폐쇄 중 | 하드 인터록. 닫힌 챔버에 가스를 넣으면 압력이 무한정 상승한다 |
| `ILK_VALVE_SAT` | 완전개방 포화 | 더 이상 압력을 낮출 수 없다 — PM 요구 신호 |

### ALM_VALVE_DRIFT 검출 범위 (시뮬레이션 실측, 기준각 26.77°)

| 고장 | 밸브각 | 드리프트 | 임계 +1.5 % 대비 |
|---|---|---|---|
| TMP 95 % 저하 | 26.88° | +0.39 % | **미검출** |
| TMP 90 % 저하 | 26.99° | +0.81 % | **미검출** |
| TMP 80 % 저하 | 27.28° | +1.88 % | 검출 |
| TMP 70 % 저하 | 27.65° | +3.27 % | 검출 |
| 밸브 마모 95 % | 27.48° | +2.65 % | 검출 |
| 밸브 마모 90 % | 28.25° | +5.52 % | 검출 |
| 밸브 마모 80 % | 30.01° | +12.07 % | 검출 |
| 밸브 마모 70 % | 32.13° | +20.01 % | 검출 |

**밸브 마모는 초기에 잡히고 펌프 저하는 20 % 이상 진행해야 잡힌다.**
같은 크기의 성능 저하라도 밸브 쪽이 밸브각에 훨씬 크게 나타나기 때문이다
(밸브는 직접 조작변수이고, 펌프는 직렬 결합으로 희석된다).
펌프 저하를 조기에 잡으려면 임계를 낮춰야 하는데, 계측 분해능 0.34 % 때문에
0.5 % 이하로 내리면 오알람 위험이 커진다. **다중 운전점 진단(§7)이나 포어라인 병행이 정공법이다.**
(다만 포어라인은 누설만 가른다 — TMP 저하와 밸브 마모는 둘 다 스루풋을 바꾸지 않아 반응하지 않는다.)

## 6. 한계 (반드시 함께 읽을 것)

1. **TMP 성능저하와 밸브 마모는 단일 운전점에서만 분리되지 않는다 — 다중 운전점이면 분리된다.**
   정상상태 식이 하나인데 미지수가 둘이므로 한 운전점만으로는 부정이다. 그러나 유량 Q 를 바꿔
   (Q, P, θ) 를 2점 이상 모으면 `P/Q = (1/C_max)·(1/f) + 1/S_pump` (f = 1 − cos θ) 가 선형이 되어
   둘 다 풀린다. 시뮬레이터 실측 오차는 **0.5 % 이내**다
   (`physics/diagnostics.py::estimate_multipoint`, 아래 §7 시퀀스 참조).
   단일 운전점 진단(IR 14/15)은 여전히 어느 한쪽을 가정하며, 그 사실을 `DI 12` 로 알린다.

2. **시험대 파라미터는 실제 장비 스펙이 아니다.** V = 0.050 m³, S_pump = 1.500 m³/s,
   C_max = 2.000 m³/s 는 시뮬레이터 설정값이다. 추정 오차(%)는 절대 스케일에 무관하므로
   진단 성능 결론은 유효하지만, 특정 장비의 절대 누설량을 말하는 것은 아니다.
3. **5 Hz 폴링은 과도응답 진단에 부족하다.** τ ≈ 0.25~0.33 s 이므로 τ/dt = 1.24~1.67 이고,
   1차계 식별에는 통상 τ/dt ≳ 5 가 필요하다. 정상상태 진단(밸브각 역산 · RoR)은 충분하다.
4. **실측에 고장 사례가 없다.** 공개 데이터셋은 정상 운전 96 장뿐이므로 진단기의 실제 성능은
   검증되지 않았다. 이것이 애초에 시뮬레이터를 만든 이유다.
5. **보안 없음.** Modbus TCP 는 인증·암호화가 없다. 폐쇄망 전제이며, 외부망 노출 금지다.

## 쉬운 요약

컴퓨터 속 가상 챔버를 진짜 장비인 것처럼 통신 규격(Modbus)에 맞춰 내보냈다.
그래서 진짜 PLC 를 붙이면 PLC 는 이게 시뮬레이터인지 모르고 평소처럼 제어한다. 장비 없이 PLC 프로그램을 시험할 수 있다.
PLC 는 압력이 아니라 **밸브 각도**를 보고 알람을 낸다. 압력은 자동제어가 붙들고 있어서 고장이 나도 안 움직이기 때문이다.
펌프 고장과 밸브 마모는 여전히 구분이 안 된다 — 식이 하나인데 모르는 값이 둘이라서다. 한계로 적어 뒀다.

## 7. 다중 운전점 진단 시퀀스 (TMP ↔ 밸브 분리)

단일 운전점에서는 정상상태 식이 하나뿐이라 C_max 와 S_pump 를 동시에 결정할 수 없다.
유량을 몇 단계로 바꿔가며 (Q, P, θ) 를 모으면 둘 다 풀린다.

    P/Q = x·(1/f) + y,     x = 1/C_max,  y = 1/S_pump,  f = 1 − cos θ

운전점마다 독립 방정식이 하나씩 생기므로 2점 이상이면 최소제곱으로 분리된다.
밸브를 많이 닫으면 밸브가 병목, 많이 열면 펌프가 병목이라는 사실을 이용하는 것이다.

### 시퀀스 (PM 창에서 수행)

1. `CMD_PROCESS_RUN` 유지, APC 자동 유지
2. `SP_MFC`(HR 1)를 4 단계로 바꾼다 — 예: 0.7 → 0.9 → 1.1 → 1.3 Pa·m³/s
3. 각 단계에서 **외란 정착 4.1 s 이상** 대기 후 `PT_CHAMBER`(IR 0)와 `ZT_VALVE`(IR 2)를 읽는다
4. 4 쌍을 최소제곱에 넣어 C_max, S_pump 를 푼다
5. 조건수가 1e3 을 넘으면 운전점이 서로 너무 가까운 것이므로 폐기하고 범위를 넓힌다

### 검증 결과 (시뮬레이터, Q 4 점 스윕)

| 실제 상태 | C_max 추정 | 오차 | S_pump 추정 | 오차 | 판정 |
|---|---|---|---|---|---|
| 정상 | 2.001 | +0.07 % | 1.493 | −0.50 % | 둘 다 정상 |
| TMP 80 % 저하 | 2.001 | +0.07 % | 1.196 | −0.30 % | **펌프 열화** |
| 밸브 C_max 80 % | 1.601 | +0.03 % | 1.496 | −0.25 % | **밸브 마모** |

**두 고장이 완전히 분리되고 오차는 0.5 % 이내다.**

> 실측 데이터셋의 Bosch 공정은 이미 두 운전점을 갖는다 — 긴 스텝 유량 600, 짧은 스텝 300.
> **밸브 각도만 기록되었다면 공정 자체가 매 사이클 이 진단을 공짜로 제공했을 것이다.**
